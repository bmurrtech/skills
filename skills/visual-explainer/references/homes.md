# Visual homes

Read when resolving where **visual-explainer** writes HTML (and optional
companion `.md`). Placement SoT steps stay in `SKILL.md`; this file lists
durable-home cues.

## Homes

| Path | Tracked? | Role |
|------|----------|------|
| `.scratch/visuals/` | No (under `.scratch/`) | Default — draft / private explore |
| `docs/visuals/` | Yes | Team, group, or commit-history visuals |

## Route to `docs/visuals/`

Use the tracked home when the ask clearly includes any of:

- **Audience:** team, group, org, stakeholders, “for everyone”
- **VCS / durability:** commit, track, git history, checked in, share in the repo
- **Docs surface:** for the docs, for the README, publish, put under docs/

Synonyms that mean the same branch count as one cue — do not require exact
wording.

## Default and soft uncertainty

No durable cue → `.scratch/visuals/`.

Phrases like “maybe share later” / “not sure if we commit” → `.scratch/visuals/`
without asking. Ask home only when the user explicitly wants help choosing.

## Companion

If a Markdown companion is requested, write it next to the HTML in the same
resolved home.
