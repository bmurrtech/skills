# Release notes template

Read when composing GitHub Release notes (step 3).

## Shape

```markdown
## Highlights
- …

## Install / artifacts
- …

## Breaking changes
- (omit section if none)

## Full changelog
(paste or link the CHANGELOG section for this version)
```

Prefer CHANGELOG section as SoT; template adds install/artifact pointers and
breaking-change callouts when present.
