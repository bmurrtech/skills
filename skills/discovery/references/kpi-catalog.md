# KPI catalog

Labels for measurable change. Tag a signal only when the room gave one. Never
invent a number; an unsized label is still useful evidence.

## Operational labels

| Label | Tag when they describe… |
|---|---|
| Hours saved | Staff time returned per cycle, week, or month |
| Cycle time | Elapsed start-to-finish time shrinking |
| Throughput | More runs of a repeatable process |
| Quality | Fewer errors, rework, or escalations |
| Adoption | People choosing to use it repeatedly |
| Automation success | Share of runs finishing without human repair |
| Tool consolidation | Fewer overlapping tools or licenses to maintain |

## Fiscal tiers

Every money-like claim gets exactly **one** tier, so nobody argues past the evidence.

| Tier | Counts when |
|---|---|
| **Hard savings** | A budget line actually drops: retired contract, fewer licenses, cancelled planned spend |
| **Cost avoidance** | Spend that would otherwise be added: new vendor, overtime, backfill, duplicate platform |
| **Capacity redirected** | Hours freed and moved to higher-value work, with no budget cut |

Unsure between tiers → pick the more conservative (capacity < avoidance < hard) and add an ask.
